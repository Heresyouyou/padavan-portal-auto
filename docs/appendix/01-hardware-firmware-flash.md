## 1. 硬件与固件选型

### 固件对比：为什么选老毛子(Padavan) 而不是 ASWiFi

| 对比项 | ASWiFi | 老毛子 Padavan |
|---|---|---|
| MT7615 无线驱动 | ⚠️ 对 K2P A2 经常识别失败 | ✅ 适配 A1/A2 |
| 内核版本 | 4.19 / 5.4 | 3.4 |
| NAT 转发性能 | 中 | 高 |
| 校园网锐捷认证 | ✅ 有 | ✅ 有（参数更细） |
| Portal 网页认证 | ✅ 图形化 | ✅ 脚本 + 守护 |
| 防检测可调性 | 依赖固件内置开关 | 灵活 |
| 管理界面 | 中文定制 | 可切中文 |

### 固件下载（hiboy 编译版，国内直连）

```
https://opt.cn2qq.com/padavan/
```

**选版本规则**：

- ✅ `K2P_DRV_V5_*.trx` — MT7615 **闭源驱动**版（WiFi 稳定）
- ❌ `K2P_V5_*.trx` — **开源驱动**版（WiFi 不稳定）
- ❌ 512M 版本（K2P 只有 128M RAM）
- ❌ `K2P_DRV_256M_*.trx` — 非 V5 的老版本

> **通用规则**：优先选带 `DRV`（闭源驱动）的版本；RAM 必须匹配硬件。

## 2. Breed 引导（刷机前提）

Breed 是 MTK 平台的不死引导，刷机/救砖都靠它。

### 进入 Breed

```
1. 路由器断电（拔电源）
2. 长按 Reset 复位键不放
3. 插电源，等约 5 秒后松开复位键
4. 电脑用网线接 LAN 口，自动获取 192.168.1.x
5. 浏览器访问 http://192.168.1.1
```

### Breed 首页自检

| 项 | 预期 |
|---|---|
| CPU | MT7621 |
| Flash | 16MB |
| RAM | 128MB |
| Wireless | **MT7615**（若显示 `N/A` → 硬件问题或 EEPROM 丢失） |

## 3. 刷机流程（⚠️ 严格按顺序）

```
① 备份（强烈推荐）
   ├── 固件备份   → 下载到本地
   └── EEPROM 备份 → 下载到本地（★ 含无线射频校准数据）

② 恢复出厂设置（必做，清 NVRAM）
   ├── 选 "Config 区（公版）"
   ├── 执行
   └── ⚠️ 绝对不要清 EEPROM，否则无线信号报废

③ 刷入固件
   ├── 固件升级 → 勾选"固件"行
   ├── 选择 K2P_DRV_V5_*.trx
   ├── ✅ 勾选"自动重启"
   └── 上传

④ 等待
   └── 进度条走完自动重启，再等 3–5 分钟完全启动（期间不要断电）
```

### 登录管理界面

```
浏览器访问 http://192.168.123.1
默认账号 admin / 密码 admin
```

> 不同版本默认 IP 可能是 `192.168.1.1` 或 `192.168.123.1`。
> 打不开就在电脑上 `ipconfig`（Windows）/ `ifconfig`（macOS）看**默认网关**，以实际为准。

### 首次登录后立即改密码

`管理 → 系统设置 → 修改密码`

## 4. 常见刷机问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 刷完 WiFi 不亮 | MT7615 驱动未初始化 | 进管理界面手动开 WiFi |
| Breed 里 Wireless 显示 N/A | EEPROM 校准数据丢失 | 刷回原厂固件确认硬件；用备份恢复 EEPROM |
| 刷完 ASWiFi 无 WiFi | 闭源驱动对 A2 适配差 | 换老毛子 Padavan |
| 管理界面打不开 | 默认 IP 不同 | 看默认网关 |
